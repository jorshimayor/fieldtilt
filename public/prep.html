The Prep Terminal

Junior to senior, four lanes: core SWE, football tech, blockchain, bounties. Every module is grounded in repos you already own — the job is converting collected knowledge into scheduled reps and shipped proof.

progress

the ladder — what each level is actually tested on

junior

Can you code cleanly under time pressure, and do you test? DSA screens, a take-home done properly, basics of HTTP/DB/git. Portfolio matters more than experience here — you already beat this bar.

mid

Can you own a feature end to end? Debugging stories, API design, trade-off talk, code review judgment. Your STAR bank IS this level's currency.

senior

Can you design systems and carry others? System design rounds, architecture narratives, mentorship signals, saying "I measured it" instead of "I think". This is the season target.

lane 1 · core swe — the reps

You forked leetcode-company-wise-problems, system-design-primer and the Xu book notes. Collecting is done; the ladder is climbed by cadence. Everything below is a repeating weekly commitment, not a one-off.

lane 2 · football tech — the show-don't-tell lane

The Hudl-family bar: TypeScript, PostgreSQL, React, GraphQL, agentic engineering, CI. You now hold live artifacts for all six. This lane is about narration and visibility, not new code.

lane 3 · blockchain — from repos to contests

Goldgard (Solidity), panoptic-v2-core (DeFi options) and stablearc-settlement-agent (stablecoin P2P settlement) prove interest with code behind it. The blockchain hiring market pays for SECURITY judgment — the path runs through audit contests, which are also your bounty lane.

lane 4 · bounties — income while you interview

Two different games: OSS feature bounties (fast, plays to your TypeScript speed) and audit contests (slower ramp, higher ceiling, compounds with lane 3). Start with the first, grow the second.
